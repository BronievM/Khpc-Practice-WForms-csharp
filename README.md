# 🖥️ Навчальна практика (Windows Forms & C#)

## 📚 Опис
Репозиторій містить результати виконання практичних робіт та підсумкового індивідуального завдання з навчальної практики. Проєкти реалізовані на мові **C#** з використанням технології **Windows Forms**.

---

## 📂 Зміст та структура
Завдання виконані згідно з **11-м варіантом**.

### 🛠️ Основні практичні роботи:
| № | Тема та об'єкти | Опис завдання | Репозиторій |
|:---:|:---|:---|:---:|
| **1** | **Задача про анкету** | Створення форми з персональними даними та керування видимістю фотографій (`PictureBox`, `Button`). | [📁 Code](https://github.com/BronievM/Khpc-Practice-WForms-csharp/tree/main/Project1_1) |
| **2** | **Обмін валюти** | Моделювання операцій обміну. Робота з розгалуженнями та перемикачами (`TextBox`, `RadioButton`). | [📁 Code](https://github.com/BronievM/Khpc-Practice-WForms-csharp/tree/main/Project2) |
| **3** | **Табулювання функції** | Програмування циклів для обчислення $y = \sin(x) + 1$. Виведення результатів у список або масив (`ListBox`, `CheckBox`). | [📁 Code](https://github.com/BronievM/Khpc-Practice-WForms-csharp/tree/main/Project3) |
| **4** | **Телефонний довідник** | Робота з файлами записів (BinaryReader/Writer), багатосторінковими блокнотами та пошуком у базі (`TabControl`, `DataGridView`). | [📁 Code](https://github.com/BronievM/Khpc-Practice-WForms-csharp/tree/main/Project4) |

### 🏆 Індивідуальне завдання (Варіант №11):

* **Функціонал:** Створення структури (5+ полів), запис масиву об'єктів у файл та реалізація пошуку ціни за назвою товару.
